这是我的第一篇博客文章。

## 为什么建这个网站

我一直想有一个真正属于自己的地方,而不是依赖第三方平台。需求很简单:

- 展示个人作品和技能
- 记录技术学习和思考
- 完全控制内容和样式

## 技术栈选择

最终选了 **Next.js 16 + React 19 + Tailwind CSS 4**,理由:

1. **SSR + 静态生成** - 性能好,SEO 友好
2. **App Router** - 现代化的路由方案
3. **MDX 支持** - 博客文章可以嵌入 React 组件
4. **部署灵活** - Vercel、自建服务器都可以

## 设计原则

整个网站遵循几个原则:

- **内容优先** - 不做花哨的装饰,让信息清晰易读
- **暗色主题** - 长时间阅读不刺眼
- **响应式** - 移动端也要好用
- **中英双语** - 同时服务国内外读者

## 后续计划
